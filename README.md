# AHSZ 极简博客

一个零依赖的轻量博客程序，原生 PHP + SQLite，无框架、无第三方库。视觉风格参考 Fuwari 主题（主题色可调、深浅色切换、响应式双栏）。

## 功能

**前台**：首页文章列表、文章详情、分类总览与分类文章列表、标签云与标签文章、文章归档、关键词搜索、分页。

**后台**：概览统计、文章管理（增删改）、分类管理、标签管理、站点设置（网站名称/标签/主题色等）、修改密码。

## 运行方式

需要 PHP 8.0+（需启用 `pdo_sqlite`、`mbstring` 扩展）。

```bash
# 在项目根目录执行
php -S 0.0.0.0:8092 router.php
```

然后访问：

- 前台：http://127.0.0.1:8092/
- 后台：http://127.0.0.1:8092/admin/index.php?m=login

Windows 用户可直接双击 `启动预览.bat`。

## 默认后台账号

- 用户名：`admin`
- 密码：`admin888`

> 注意：这是本地演示账号。若部署到公网，请登录后台「修改密码」立即更改。

## 目录结构

```
.
├── index.php          # 前台单入口（路由分发）
├── categories.php     # 独立分类页
├── router.php         # PHP 内置服务器路由
├── inc/               # 配置、数据库、公共函数
├── views/             # 前台视图模板
├── admin/             # 后台入口与视图
├── assets/            # CSS / JS
├── data/blog.db       # SQLite 数据库（含 4 分类 40 篇示例文章）
└── 启动预览.bat        # Windows 一键启动
```

## 数据库

使用 SQLite，位于 `data/blog.db`，程序首次运行会自动建表（幂等）。仓库中附带了示例数据，方便直接预览。若需空站，删除该文件后访问首页即可自动重建。

数据库共 6 张表：`posts`、`categories`、`tags`、`post_tags`、`options`、`admins`。

## 说明

- 站点地址跟随访问时的 Host 自动生成，本地 IP / 局域网 IP / 域名均可直接访问。
- 编程语言：PHP 8.x；数据库：SQLite 3；无 Composer 依赖。
