# AHSZ 极简博客

零依赖的轻量博客程序：原生 PHP 8 + **MySQL**，无框架、无第三方库。视觉风格参考 Fuwari 主题（主题色可调、深浅色切换、响应式双栏）。

## 功能

**前台**：首页文章列表、文章详情、分类总览与分类文章列表、标签云与标签文章、文章归档、关键词搜索、分页。

**后台**：概览统计、文章管理（增删改/批量删除/分页/分类筛选/置顶）、分类管理、标签管理、站点设置、修改密码、**数据备份与恢复**（下载 SQL / 服务器备份 / 上传或选择文件恢复，恢复前自动生成回滚备份）。

**安装**：独立的 `install/` 安装向导，环境检测 → 数据库连接测试 → 自动建库建表 → 管理员初始化 → 自动锁定。安装只创建空站点，不填充任何演示数据。

## 运行环境

- PHP 8.0+，需启用 `pdo_mysql`、`mbstring` 扩展
- MySQL 5.7+ / MariaDB 10.2+（账号需具备建库、建表权限；若事先建好库则只需建表权限）

## 安装步骤

1. 启动 PHP 服务器（项目根目录执行）：

   ```bash
   php -S 0.0.0.0:8092 router.php
   ```

   Windows 可直接双击 `启动预览.bat`。

2. 浏览器打开 **独立安装页**：http://127.0.0.1:8092/install/

3. 填写数据库主机、端口、库名、账号密码（可先点「测试数据库连接」）。库不存在时会尝试自动创建。

4. 设置网站名称和管理员账号密码。安装后为**空站点**，不含任何文章、分类或标签，需到后台自行发布内容。

5. 点击「开始安装」。成功后会在 `data/` 下生成：
   - `db.config.php`：数据库连接配置（含密码，**不要提交到 Git**）
   - `install.lock`：安装锁，安装页随即失效

6. 安装向导不提供前台跳转链接，请自行访问：

   - 前台：http://127.0.0.1:8092/
   - 后台：http://127.0.0.1:8092/admin/

> 如需重新安装：手动删除 `data/install.lock` 与 `data/db.config.php` 后再次访问 `/install/`。

## 性能优化

- **OPcache**：`启动预览.bat` 启动时加载 Zend OPcache，避免每次请求重复编译 PHP 脚本。
- **页面缓存**：首页、分类页、标签页、归档页的完整 HTML 缓存到 `data/cache/`（有效期 5 分钟）；后台任何内容变更立即清空缓存。文章详情因阅读量实时 +1 不走缓存，搜索页也不缓存。
- **查询优化**：文章列表批量预加载分类与标签，消除逐篇查库的 N+1 问题；站点统计合并为单条 SQL 并在请求内复用；`posts` 表增加首页/分类复合索引。首页 SQL 查询从 29 次降到 12 次，缓存命中时为 0 次。
- **传输优化**：HTML/CSS/JS 启用 gzip 压缩；CSS/JS 带 ETag 与 304 条件请求，浏览器缓存 1 天；前台页面允许浏览器缓存 60 秒。实测首页响应时间约 25ms → 缓存命中约 4ms，传输体积 18KB → 3.6KB。


## 数据备份与恢复

后台侧栏「系统 → 数据备份」提供三种操作：

1. **下载备份文件**：把 6 张表的结构与全部数据导出为 UTF-8 SQL 文件，直接下载到本地。
2. **保存到服务器**：备份文件写入 `data/backups/`，可在列表中下载、恢复或删除。
3. **从文件恢复**：上传本站导出的 `.sql`，或从服务器备份列表选择一份恢复。恢复前会自动把当前数据另存为 `auto-before-restore-*.sql`，可随时回滚。

安全性：所有操作需登录并带 CSRF 令牌；恢复仅接受带本站标识的文件，逐条校验语句且只放行白名单表的 `DROP/CREATE/INSERT`，全部校验通过后才执行；备份文件无法通过 URL 直接下载。


## 数据库

MySQL，6 张表：`posts`、`categories`、`tags`、`post_tags`、`options`、`admins`。引擎 InnoDB，字符集 utf8mb4。表结构由 `inc/schema.php` 定义，仅在安装时创建。

站点地址跟随访问时的 Host 自动生成，本地 IP / 局域网 IP / 域名均可直接访问。仓库中不含任何默认管理员密码，账号在安装时自行设定。
